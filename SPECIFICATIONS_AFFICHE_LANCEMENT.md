# Spécifications Techniques Détaillées - Affiche de Lancement

## 📐 DIMENSIONS PRÉCISES PAR ZONE (Format A4 / 8.5" x 11")

### Zone 1: En-tête (20% = 2.2" / 59.4mm hauteur)

```
┌─────────────────────────────────────────────┐
│ Marge: 0.25" (6mm)                         │
│                                             │
│ [LOGO] 0.5" (12mm) depuis haut/gauche      │
│ Max: 2" (50mm) hauteur                     │
│                                             │
│ TITRE PRINCIPAL                             │
│ Taille: 48-60pt                            │
│ Marge bas: 0.3" (8mm)                      │
│                                             │
│ [Badge Campagne]                           │
│ Position: Haut droite                      │
│ Taille: 1.8" x 1" (46mm x 25mm)          │
│ Bordure: 3pt, couleur accent               │
└─────────────────────────────────────────────┘
```

**Spécifications Logo:**
- Format accepté: PNG transparent, SVG, JPG fond blanc
- Ratio: Maintenir proportions originales
- Position alternative si pas de logo: Centrer nom école en grand (48pt) avec icône 🏫 (40pt)

**Spécifications Badge:**
- Fond: Couleur accent vive (vert #10B981 ou orange #F59E0B)
- Texte: Blanc, Bold
- Contenu:
  - Ligne 1: "Campagne #[NUMÉRO]" (16pt)
  - Ligne 2: "Début: [DATE]" (12pt)
  - Ligne 3: "Inscris-toi MAINTENANT!" (10pt, italique)


**Spécifications QR Code:**
- **Taille CRITIQUE**: 2.5" x 2.5" (63.5mm x 63.5mm) - MINIMUM ABSOLU
- Zone tranquille: 0.25" (6mm) blanc autour (ESSENTIEL pour scan)
- Contraste: Noir (#000000) sur blanc pur (#FFFFFF)
- Correction d'erreur: Niveau M (15%) minimum, idéalement H (30%)
- Marge depuis bord: 0.5" (12mm)
- Position: Côté droit (zone naturelle pour pouce)

**Texte sous QR:**
- "Scanne-moi!" (16pt, Bold, centré)
- Couleur: Couleur accent
- Espacement: 0.2" (5mm) sous QR

**Code Campagne:**
- Badge: 2.5" x 0.8" (64mm x 20mm)
- Fond: Couleur accent vive (vert ou orange)
- Texte: Blanc, 28pt, Bold, Monospace
- Format: "[CODE]-C[NUMÉRO]"
- Radius: 8pt
- Padding: 0.2" (5mm) interne

**URL Alternative:**
- Texte: "Ou va sur jappuie.ca et entre le code"
- Taille: 11pt, Regular
- Couleur: Gris moyen (#6B7280)
- Position: Sous le code ou à gauche du QR

**Fond Zone 5:**
- Couleur: Couleur accent très pâle (#EFF6FF pour bleu, #ECFDF5 pour vert)
- Bordure supérieure: 3pt, couleur accent
- Padding: 0.3" (8mm) interne

- Fond: `--white`

- Texte: `--gray-700`

**Zone 5 (CTA):**
- Fond: `--green-50` ou `--blue-50` (très pâle)

- Code campagne: Fond `--green-600`, texte blanc

## 📏 ESPACEMENTS ET MARGES PRÉCIS

### Marges Globales
- **Bordure**: 0.25" (6mm) de tous les côtés
- **Zone de sécurité texte**: 0.5" (12mm) depuis bords

### Espacement Entre Zones
- **Zone 1 → Zone 2**: 0.4" (10mm)
- **Zone 2 → Zone 3**: 0.3" (8mm)
- **Zone 3 → Zone 4**: 0.3" (8mm)
- **Zone 4 → Zone 5**: 0.2" (5mm)

### Espacement Interne
- **Entre blocs bénéfices**: 0.4" (10mm) vertical, 0.3" (8mm) horizontal
- **Entre cartes avantages**: 0.2" (5mm)
- **Entre étapes processus**: 0.3" (8mm)
- **Padding interne blocs**: 0.3" (8mm)
- **Padding interne cartes**: 0.25" (6mm)

## 📊 PLACEHOLDERS / VARIABLES DYNAMIQUES

### Variables Requises

```
[NOM_ÉCOLE]              - Nom complet de l'école
[NUMÉRO_CAMPAGNE]        - Numéro de la campagne (ex: 1, 2, 3)
[DATE_DÉBUT]            - Date de début (format: "15 janvier 2025")
[DATE_FIN]              - Date de fin (format: "28 février 2025")
[CODE_CAMPAGNE]         - Code campagne (ex: "ABC123-C1")
[OBJECTIF_FINANCIER]     - Objectif en dollars (ex: "$5,000")
[MONTANT_CASH]          - Montant argent comptant par produit (ex: "$2.50")
[MONTANT_COMPTE]        - Montant crédit scolaire par produit (ex: "$1.50")
```

### Exemples de Calculs

**Exemple Concret Argent:**
- Si MONTANT_CASH = $2.50
- Texte: "Vends 10 produits = $25 en poche!"
- Calcul: MONTANT_CASH × 10

**Exemple Concret Total:**
- Si MONTANT_CASH = $2.50 et MONTANT_COMPTE = $1.50
- Total par produit = $4.00
- Texte optionnel: "Gagne $4.00 par produit vendu!"

## ✅ CHECKLIST TECHNIQUE SPÉCIFIQUE

## 🎯 PRIORITÉS ABSOLUES

### Priorité 1 (Critique - Doit Fonctionner)
1. **QR Code scannable** - C'est l'action principale
2. **Titre clair** - Comprendre en 3 secondes
3. **Code campagne lisible** - Backup si QR échoue
4. **Bénéfices clairs** - Motiver l'inscription

### Priorité 2 (Important - Maximise Conversion)
5. **Message d'urgence** - Créer action immédiate
6. **Processus simple** - Réduire friction
7. **Avantages d'être premier** - Créer FOMO
8. **Exemples concrets** - Rendre tangible

### Priorité 3 (Souhaitable - Améliore Expérience)
9. **Logo école** - Renforcer confiance
10. **Design professionnel** - Inspirer confiance
11. **Couleurs harmonieuses** - Plaisir visuel
12. **Décoration subtile** - Rendre attrayant
