# Scripts de Vidéos Tutoriels - Jappuie.ca

## Vidéo 1: Tutoriel Étudiant

### Objectif
Guider les étudiants dans leur parcours sur Jappuie, de l'inscription à la vente de produits.

### Points Clés à Couvrir

1. **Introduction (0:00 - 0:30)**
   - Présentation de Jappuie
   - Pourquoi utiliser Jappuie comme étudiant
   - Avantages de la plateforme

2. **Inscription et Connexion (0:30 - 1:30)**
   - Comment s'inscrire sur la plateforme
   - Remplir les informations parentales requises
   - Vérification de l'email
   - Se connecter à son compte

3. **Rejoindre une Campagne (1:30 - 2:30)**
   - Comment rejoindre une campagne via le code ou le lien QR
   - Comprendre les objectifs personnels
   - Voir les produits disponibles

4. **Personnaliser sa Boutique (2:30 - 4:00)**
   - Accéder à la personnalisation
   - Choisir un nom pour sa boutique
   - Personnaliser la description
   - Ajouter une photo (optionnel)
   - Configurer les options de livraison

5. **Partager et Vendre (4:00 - 5:00)**
   - Obtenir son lien unique de boutique
   - Comment partager le lien (réseaux sociaux, email, SMS)
   - Expliquer les produits aux clients potentiels
   - Suivre les commandes reçues

6. **Suivre ses Statistiques (5:00 - 5:30)**
   - Accéder au tableau de bord
   - Comprendre les statistiques de vente
   - Voir son objectif personnel et les progrès
   - Consulter l'historique des commandes

7. **Conclusion (5:30 - 6:00)**
   - Résumé des étapes clés
   - Conseils pour maximiser les ventes
   - Support et ressources disponibles

## Vidéo 2: Tutoriel École

### Objectif
Guider les gestionnaires d'école dans la création et la gestion de campagnes de financement.

### Points Clés à Couvrir

1. **Introduction (0:00 - 0:30)**
   - Présentation de Jappuie pour les écoles
   - Avantages de la plateforme multi-fournisseurs
   - Vue d'ensemble du processus

2. **Inscription de l'École (0:30 - 2:00)**
   - Créer un compte gestionnaire d'école
   - Remplir les informations de l'école
   - Télécharger le logo de l'école
   - Attendre l'approbation (si nécessaire)

3. **Créer une Campagne (2:00 - 4:30)**
   - Accéder à la création de campagne
   - **Sélectionner un fournisseur** (nouveau - important!)
   - Choisir les dates (début, fin, livraison)
   - Définir l'objectif financier
   - Configurer les heures de distribution
   - Sélectionner les produits du fournisseur
   - Personnaliser les prix (si autorisé)
   - Configurer les parts de profit
   - Configurer les dons étudiants/école

4. **Gérer les Participants (4:30 - 5:30)**
   - Inviter des étudiants à rejoindre la campagne
   - Générer la lettre aux parents avec QR code
   - Voir la liste des participants
   - Gérer les objectifs personnels

5. **Suivre les Progrès (5:30 - 6:30)**
   - Accéder au tableau de bord de campagne
   - Voir les statistiques en temps réel
   - Suivre les ventes par étudiant
   - Consulter les commandes
   - Générer des rapports

6. **Gérer l'Équipe (6:30 - 7:00)**
   - Inviter d'autres gestionnaires
   - Gérer les permissions
   - Voir les membres de l'équipe

7. **Outils de Vente (7:00 - 7:30)**
   - Générer des affiches personnalisées
   - Créer des campagnes email
   - Outils de marketing disponibles

8. **Conclusion (7:30 - 8:00)**
   - Résumé des fonctionnalités clés
   - Conseils pour une campagne réussie
   - Support disponible

## Vidéo 3: Tutoriel Fournisseur

### Objectif
Guider les fournisseurs dans la gestion de leur compte, catalogue de produits et campagnes.

### Points Clés à Couvrir

1. **Introduction (0:00 - 0:30)**
   - Présentation de Jappuie pour les fournisseurs
   - Avantages de rejoindre la marketplace
   - Vue d'ensemble du tableau de bord fournisseur

2. **Inscription et Onboarding (0:30 - 2:30)**
   - Créer un compte fournisseur
   - Remplir les informations de l'entreprise
   - Télécharger le logo
   - Informations de paiement
   - Auto-approbation (si tous les champs requis sont remplis)

3. **Gérer le Catalogue de Produits (2:30 - 5:00)**
   - Accéder à la gestion des produits
   - Ajouter un nouveau produit
   - Remplir les informations (nom, description, prix, coût)
   - Télécharger les images du produit
   - Ajouter les attributs (sans gluten, végétarien, etc.)
   - Modifier un produit existant
   - Organiser l'ordre d'affichage des produits
   - Activer/désactiver des produits

4. **Gérer les Prix (5:00 - 5:30)**
   - Comprendre la structure de prix
   - Prix de vente vs coût
   - Comment les écoles peuvent personnaliser (si autorisé)

5. **Suivre les Campagnes (5:30 - 6:30)**
   - Voir toutes les campagnes utilisant vos produits
   - Approuver/rejeter des campagnes
   - Voir les statistiques par campagne
   - Gérer les verrouillages (prix, dates)

6. **Gérer les Écoles (6:30 - 7:00)**
   - Voir les écoles partenaires
   - Approuver de nouvelles écoles
   - Consulter l'historique des relations

7. **Gérer l'Équipe (7:00 - 7:30)**
   - Inviter des gestionnaires à votre compte fournisseur
   - Définir les rôles (owner, admin, member)
   - Gérer les permissions

8. **Statistiques et Rapports (7:30 - 8:00)**
   - Accéder aux analytics
   - Voir les ventes totales
   - Analyser les performances par produit
   - Exporter les données

9. **Paramètres et Configuration (8:00 - 8:30)**
   - Mettre à jour les informations de l'entreprise
   - Gérer les méthodes de paiement
   - Configurer les notifications

10. **Conclusion (8:30 - 9:00)**
    - Résumé des fonctionnalités clés
    - Conseils pour maximiser les ventes
    - Support et ressources disponibles

## Notes Générales

- **Durée cible**: 5-9 minutes par vidéo
- **Style**: Démonstration en direct avec narration claire
- **Format**: Screen recording avec voix off
- **Langue**: Français (Québec)
- **Ton**: Professionnel mais accessible, encourageant

### Éléments Visuels Recommandés
- Utiliser des données de démonstration réalistes
- Mettre en évidence les fonctionnalités importantes
- Utiliser des annotations/pointers pour guider l'attention
- Inclure des transitions fluides entre les sections
- Ajouter des sous-titres pour l'accessibilité
